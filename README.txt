SUPERSTORE CLASS PRACTICE

1. Extract the whole ZIP before opening it.
2. Open this superstore_app folder in Antigravity or another editor.
3. In a terminal in this folder, use the intended Python environment:
       python -m pip install -r requirements.txt
       python app.py
4. Open http://127.0.0.1:8050/ . Keep the terminal running.
5. To stop: Ctrl+C. After an edit: save, stop, run again, refresh.

app.py is COMPLETE: imports, data reading/preparation, app, layout,
callback/helper functions, and the guarded runner. The data and CSS live
beside it. Do not copy only the last function into a new empty file.

The starter has Region + Year, two graphs, a category click, Reset,
and a summary. Customize one useful feature with the tutorial prompt.

One CSV row is one order-product line. Row ID is unique. No Order ID is
present, so counts are Order lines, not Orders. Negative Profit stays.
This is a starting point for the group project. Hosting and other project
deliverables follow the assigned handout.
